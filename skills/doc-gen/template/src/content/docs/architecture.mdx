## 分层说明

### <span class="layer-badge adapter">Adapter 接口层</span>

负责协议适配：REST Controller、MQ Consumer、定时任务 Scheduler

### <span class="layer-badge client">Client 契约层</span>

对外暴露的 API 契约：ServiceI 接口、CO/Cmd/Query 对象

### <span class="layer-badge application">Application 应用层</span>

用例编排层：CmdExe/QryExe 执行器、Assembler 组装器、事务管理

### <span class="layer-badge domain">Domain 领域层</span>

核心领域模型：Entity 实体、ValueObject 值对象、DomainService 领域服务、Repository 仓储接口

### <span class="layer-badge infrastructure">Infrastructure 基础设施层</span>

技术基础设施：Repository 实现、ACL 防腐层、外部渠道网关、配置
